# Vendor Renewal Reconciler — v0.1

**Status:** HYPOTHESIS  
**Source:** BUILD / BUNDLE

## Product

Detect commercial inconsistencies between:
- contract terms
- invoices
- renewal notices
- actual charges

Examples:
- unexpected price change
- duplicate subscription
- wrong seat count
- renewal-date mismatch
- charge outside an approved term

## Differentiation

Do not build a generic spend dashboard.

The unit of value is an explainable exception:

expected state -> observed charge -> evidence -> action

## Customers
SMBs, finance operations, agencies, procurement teams.

## Channels
Direct, accounting partners, procurement consultants, API.

## Kill test
A pilot customer must uncover a meaningful exception or enough recurring review effort to justify payment.
