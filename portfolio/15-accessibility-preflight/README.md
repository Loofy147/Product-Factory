# Accessibility Preflight — v0.1

**Status:** HYPOTHESIS  
**Source:** BUILD / BUNDLE

## Product

A practical pre-release accessibility check for websites and digital documents.

Input:
- URL or artifact
- target rule profile

Output:
- deterministic checks
- manual-review items
- severity
- evidence
- suggested remediation
- regression baseline

## Differentiation

Do not compete as a full accessibility consultancy or generic scanner.

Start with **pre-release gating** for agencies and small teams.

## Channels
Browser extension, CI/CLI, agencies, web-platform ecosystems, direct SaaS.

## Moat hypothesis
Versioned rule packs, regression history, and actionable evidence rather than a raw score.

## Kill test
The report must produce fixes users can implement and prevent repeated regressions.
