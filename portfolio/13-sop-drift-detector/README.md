# SOP Drift Detector — v0.1

**Status:** HYPOTHESIS  
**Source:** BUILD / BUNDLE

## Product

Detect when documented procedures no longer match the live workflow.

Input:
- documented procedure
- captured workflow sequence

Output:
- unchanged steps
- changed steps
- missing steps
- undocumented behavior
- evidence snapshots

## Target buyers
Agencies, operations teams, franchises, and process-heavy businesses.

## Differentiation

Workflow capture is established as a useful category. This product focuses on the next lifecycle problem: **procedure drift after capture**.
