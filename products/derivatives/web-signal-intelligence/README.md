# Web Signal Intelligence

Downstream product built on the open-source Webdog base.

## Our improvement

Webdog provides change monitoring, diffs, screenshots and notifications. Our product layer adds a conservative signal classification step:

CHANGE -> CLASSIFY -> CRITICAL / ACTIONABLE / LOW-NOISE

The first implementation is intentionally deterministic. It can later be connected to Webdog alert events.
