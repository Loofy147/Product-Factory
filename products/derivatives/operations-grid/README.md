# Operations Grid

Downstream product built on the open-source Grist Community Edition base.

## Our improvement

Package a relational spreadsheet for operational control:
- supplier register
- customer register
- evidence register
- renewal tracker
- simple exception queue

The product layer adds validated templates and deterministic row checks.
