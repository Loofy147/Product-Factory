# Evidence Canvas

Downstream product built on the open-source Excalidraw base.

## Our improvement

Turn the general whiteboard into a packaged evidence/decision canvas:
- claim -> evidence -> contradiction -> decision
- requirement -> artifact -> check -> finding
- system -> dependency -> state -> result
- experiment -> observation -> interpretation -> decision

## Commercial layer

Ship opinionated templates, evidence-board starter packs, export conventions and review workflows.

The upstream editor remains MIT-licensed; our templates, workflow conventions and product packaging are our layer.
