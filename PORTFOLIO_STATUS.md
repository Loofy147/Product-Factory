## New portfolio objective

Build a multi-product, multi-channel catalog.

A product can be:
- entirely built in-house
- sourced for resale
- licensed / white-labeled
- bundled / composed

The key metrics are:
- demand
- margin
- channel count
- repeatability
- support burden
- legal/contractual viability
- resilience to any single platform

## Execution rule
