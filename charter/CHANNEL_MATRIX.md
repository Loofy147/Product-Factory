# Channel Matrix v0.1

Every product is evaluated against multiple independent distribution channels.

## Primary channel classes

- Direct website / checkout
- SaaS marketplaces
- App ecosystems
- Browser extension stores
- B2B direct sales
- Agencies / consultants
- Affiliate / referral
- Authorized reseller network
- API / developer distribution
- OEM / white-label
- Bundles / partnerships
- Crypto-native marketplaces where legally and commercially appropriate

## Channel independence rule

Do not make a product dependent on one marketplace when another economically viable channel can be added.

A channel is useful only when:
- target customers are present
- listing/eligibility is achievable
- economics are viable
- fulfillment works
- support burden is manageable

## Portfolio map

For each product record:

Product
-> source model (BUILD / RESELL / WHITE-LABEL / BUNDLE)
-> target customer
-> channel
-> offer/SKU
-> delivery mechanism
-> price
-> gross margin
-> support owner
-> compliance requirements
-> channel-specific constraints

## Strategic objective

The portfolio should progressively create:

**many products × many channels**

rather than:

**one product × one platform**
